# 中国語学習クイズ

GitHubリポジトリ `tyuugokugo` で公開する、中国語の単語・文法と英単語を学べる静的サイトです。「中国語 拼音クイズ」、日本語文を中国語文へ直す「中国語 文法クイズ」、Chapter別の「英単語・英熟語」を収録しています。外部ライブラリやビルド処理を使わず、ブラウザだけで動作します。

## 主な機能

- 10問・20問・30問・40問・50問・選択中の課の全問から出題数を選択
- 全77語を第1課〜第6課に分類し、複数の課を組み合わせて出題
- 「拼音→簡体字」「日本語→簡体字」「確認モード」の3種類の学習モード
- Fisher–Yates法による、重複のないランダム出題
- 日本語の意味を必要なときだけ表示
- Web Speech APIによる中国語の発音再生
- Enterキーによる答え合わせと次の問題への移動
- 空白や空欄記号を除外した解答判定
- 得点、正答率、全解答履歴の表示
- 間違えた問題を `localStorage` に保存
- 保存した間違いだけを復習し、正解した問題を保存一覧から削除
- 中国語・拼音・日本語の意味を検索できる全77項目の単語一覧
- 単語一覧の課別表示と、検索と併用できる課フィルター
- ホームから閲覧でき、文字を選択・コピーできるHTMLの声調組み合わせ表
- 解答済み問題だけを集計するクイズ途中結果
- 確認済み単語だけを表示する確認完了・確認途中結果
- 結果画面の上部・下部のどちらからでもホームへ戻れる操作
- 確認した単語群から通常の入力式クイズを開始
- 「最初からやり直す」を上部の補助メニューに配置し、確認後に再開始
- History APIによる単語一覧・クイズ・結果画面のブラウザ履歴対応
- スマートフォンのページ全体を利用するレスポンシブUI
- PC・スマートフォン対応
- 日本語の文章から中国語の文章へ直す、全73項目の文法クイズ
- 文法クイズ専用の入力式・確認モード、文章一覧、結果画面
- Chapter1〜Chapter7、全49語の英単語・全21個の英熟語一覧
- 行ごとに日本語訳を表示・非表示にできる英語学習機能
- APIを使わず1分ごとに更新するApex Legendsランクマップ表示

## 音声再生について

発音機能はブラウザ標準のWeb Speech APIを使用し、中国語音声を優先して再生します。実際の声質や発音は、利用する端末やブラウザにインストールされている中国語音声によって異なる場合があります。

「日本語→簡体字」では、音声から答えが分からないように答え合わせ前は発音ボタンを表示しません。答え合わせ後は正解の簡体字、拼音、意味とともに発音を確認できます。

Web Speech APIに対応していないブラウザでは発音ボタンが無効になり、入力式モード・確認モード・単語一覧のその他の機能はそのまま利用できます。外部の音声ファイルや有料APIは使用していません。

## 学習モード

学習モードは次の3種類です。旧「クイズモード」は「拼音→簡体字」へ名称を変更しました。

- **拼音→簡体字**：拼音を見て、対応する簡体字を入力します。
- **日本語→簡体字**：日本語の意味を見て、対応する簡体字を入力します。答え合わせ後に簡体字、拼音、意味、発音を確認できます。
- **確認モード**：入力や正誤判定を行わず、拼音・簡体字・意味・発音を確認します。

確認モードを最後まで進めると確認完了画面、途中で終了すると確認済み単語だけの確認途中結果を表示します。確認済みの単語群から入力式クイズを開始する場合は、最後に選択した入力式モードを使用し、問題を再度シャッフルして出題します。

確認モードの「答えを見る」「次の単語」「確認を終了する」は、同じ位置にある1つの主要操作ボタンの文言と処理を状態に応じて切り替えています。答えはボタンの下に表示されるため、答えを開いても操作ボタンの位置は変わりません。

確認モードでは正誤を記録しないため、間違い復習用の `localStorage` は変更しません。「間違えた問題だけ復習」は、ホームで「日本語→簡体字」を選択中なら日本語形式、それ以外は拼音形式で開始します。

選択した学習モードは `tyuugokugo-learning-mode`、最後に選択した入力式モードは `tyuugokugo-last-input-mode` として `localStorage` に保存します。旧保存値の `quiz` と `pinyin` は「拼音→簡体字」、`review` は「確認モード」として読み込み、不正な値は「拼音→簡体字」へ戻します。

クイズ画面の「最初からやり直す」は、主要な解答ボタンから離れた上部の「その他」メニューにあります。選択後に確認ダイアログが表示され、確定した場合だけ同じ出題数・同じモードで新しく開始します。

## 中国語 文法クイズ

ホーム画面では「中国語 拼音クイズ」の直下に、独立した「中国語 文法クイズ」を表示します。文法用の学習モードは「日本語→中国語」と「確認モード」の2種類です。

- **日本語→中国語**：日本語の文章を見て対応する中国語の文章を入力し、正誤を判定します。
- **確認モード**：中国語を入力せず、日本語から答えを考えてから中国語文と発音を表示します。正誤判定や得点計算は行いません。

確認モードの「答えを見る」「次の文章」「確認を終了する」は、同じ位置にある1つの主要操作ボタンを状態に応じて切り替えます。確認完了・途中結果では確認済み文章だけを表示し、その文章群から通常の入力式文法クイズを開始できます。

文法問題は第1課〜第6課の全73項目です。各課の問題数は、第1課11項目、第2課10項目、第3課12項目、第4課16項目、第5課11項目、第6課13項目です。第4課には量詞表の「一个苹果」から「五条领带」までの7項目も含みます。

文法クイズ専用のチェックボックスで複数の課を選択でき、出題数は10問・20問・30問・40問・50問・選択課の全問から選べます。出題数が候補数を超える場合は候補を重複させずすべて出題し、Fisher–Yates法で順番をシャッフルします。

正解判定では、中国語・日本語・半角の句読点、疑問符、感嘆符、引用符、半角・全角空白、改行、タブを取り除いて比較します。漢字、語順、文法語、儿化、数量詞、否定表現は変更せず比較するため、句読点や空白がなくても正解になりますが、異なる文や拼音は正解になりません。

文法クイズ開始ボタンの直下には補助操作の「文章一覧を見る」ボタンがあります。文章一覧では第1課〜第6課の全73項目を課別に表示し、課フィルターと中国語・日本語・課・POINTの検索を同時に利用できます。各文章の中国語全文を発音できます。

入力式クイズ、確認モード、文章一覧、両モードの結果画面は、すべて `grammar-data.js` の同じ `grammarQuestions` を参照します。73項目を別配列やHTMLへ重複して記述していません。

文法クイズの学習モード、課選択、出題数、問題列、入力式の解答履歴、確認済み履歴、途中結果は拼音クイズと別に管理します。設定は `tyuugokugo-grammar-learning-mode`、`tyuugokugo-grammar-selected-lessons`、`tyuugokugo-grammar-question-count` を使用し、単語クイズの間違い一覧へ文法問題を追加しません。文法確認モードも間違い用の `localStorage` を変更しません。

## 英単語・英熟語

ホーム画面では「中国語 文法クイズ」の直下に、独立した「英単語・英熟語」ブロックを表示します。Chapter1〜Chapter7と「全Chapter」のボタンから共通の一覧画面へ移動でき、各Chapterに英単語7語と英熟語3個、全Chapterで英単語49語と英熟語21個を収録しています。英単語と英熟語は、`english-vocabulary-data.js` の同じChapterオブジェクト内にある `words` と `phrases` で管理しています。

各Chapterでは英単語表の下に英熟語表を表示します。どちらも「項目」「日本語の意味」「操作」の3列で、ページを開いた直後はすべての日本語訳が非表示です。各行の「表示」「非表示」で意味を個別に切り替えられます。また、両方の表に独立した「すべて表示」「すべて非表示」ボタンがあり、英単語の一括操作は英熟語へ、英熟語の一括操作は英単語へ影響しません。別のChapterへ移動した場合や同じChapterを開き直した場合は、両方の表示状態がリセットされます。

各Chapterページの上部には前後移動ボタンがあり、ページを再読み込みせず隣のChapterへ移動できます。Chapter1には前のChapterボタン、Chapter7には次のChapterボタンを表示せず、空のグリッド領域で中央見出しの位置を維持します。従来の操作説明文は削除し、見出し、単語数、表の順で簡潔に表示します。

「全Chapter」ページでは、同じ `englishVocabularyChapters` データからChapter1〜Chapter7の英単語表と英熟語表を順に生成し、全70項目をChapter別に確認できます。全Chapterでも日本語訳は初期状態で非表示で、各Chapter・各表の一括操作は互いに独立しています。

英単語一覧はHistory APIに対応し、前後Chapterの移動履歴とブラウザバックが連携します。ページ内の「ホームに戻る」、ブラウザの戻るボタン、iPhone Safariの戻るスワイプも利用できます。英単語データは中国語データと分け、`english-vocabulary-data.js` で管理しています。

## 現在のランクマップ

ホーム画面の「英単語・英熟語」の下に「現在のランクマップ」ブロックを表示します。外部APIは使わず、JavaScriptだけでApex Legendsのランクマップローテーションを計算します。

対象マップは Storm Point、World’s Edge、E-District の3つです。1マップ4時間30分、3マップで13時間30分の順番を繰り返し、日本時間2026年7月27日11:00のStorm Point開始を基準にしています。現在のマップと残り時間、次のマップに加え、現在枠とその後4枠を合わせた5件のローテーションを画像付きで表示します。日付をまたぐ枠を区別できるよう、一覧の時間帯は日本時間の月日と24時間表記の時刻で表示します。

ローテーション一覧の下には「S29 SP2終了まで」を表示します。終了時刻は日本時間2026年8月5日02:00で、残り時間を日・時間・分に分けて表示します。終了後は負の時間を表示せず、「S29 SP2は終了しました。」へ切り替わります。外部APIは使用せず、マップ表示と残り時間を同じ処理で1分ごとに更新し、ブラウザをバックグラウンドから戻したときにも再計算します。

## 手書き入力

スマートフォンでは、簡体中国語の手書きキーボードを利用して解答できます。キーボードの追加・切り替え方法は端末によって異なります。

サイト側からキーボードを自動的に「簡体中国語・手書き」へ切り替えることはできません。クイズへ解答するときは、ユーザー自身で端末のキーボードを「簡体中国語・手書き」に切り替えてください。ホームの注意書きには絵文字やアイコンを使用していません。

## 課の選択

単語データは次の範囲で分類しています。

- 第1課：`礼堂`〜`一定`（14語）
- 第2課：`晚上`〜`爱吃`（17語）
- 第3課：`不好意思`〜`进去`（12語）
- 第4課：`点`〜`无酒精啤酒`（11語）
- 第5課：`说`〜`发音`（12語）
- 第6課：`快要～了`〜`学费`（11語）

ホームでは第1課〜第6課をチェックボックスで複数選択できます。「全課」は6課をまとめて選択・解除する操作で、初回は全課が選択されています。選択した課は `localStorage` に保存され、次回アクセス時に検証して復元されます。不正な保存値は使用せず、全課選択へ戻します。

出題数の「全問」は全77語固定ではなく、現在選択している課に含まれる全単語を意味します。指定した出題数が候補語数を超える場合は、重複を作らず候補語をすべて出題します。課選択と出題数は3つの学習モードすべてに適用され、途中で「最初からやり直す」を選んでも開始時点の課・出題数・学習モードが維持されます。

「間違えた問題だけ復習」は、保存済みの間違いのうちホームで選択している課に属する単語だけが対象です。単語一覧は課ごとに見出しを付けて表示し、全課または1つの課で絞り込みながら、中国語・拼音・日本語の意味を検索できます。

## 声調組み合わせ表

ホーム画面の「単語一覧を見る」の下にある「声調組み合わせ表」ボタンから、中国語の単語を声調の組み合わせごとにまとめた表を閲覧できます。

声調組み合わせ表は画像ではなく、HTMLの `table` 要素で構成しています。2音節の5×5表に加えて、1音節、3音節、4・5音節の表を表示し、表内の文字は通常のテキストとして選択・コピーできます。スマートフォンでは2音節表の領域だけを横スクロールでき、下部の3表は縦並びになります。表示に画像ファイルは必要ありません。

声調組み合わせ表ページはHistory APIへ連携しているため、ブラウザの戻るボタンやiPhone Safariの戻るスワイプでホームへ戻れます。

## スマートフォン対応

解答入力欄と検索欄は16px以上の文字サイズにし、iPhone Safariで仮想キーボードを表示した際の自動ズームを防いでいます。画面には `100dvh` を使用し、入力欄へフォーカスしたときは必要な場合だけ操作領域が見える位置へスクロールします。

クイズ・結果・単語一覧は中央の小さなカードに閉じ込めず、ページ幅全体を利用するレスポンシブUIです。viewportでは `user-scalable=no` や `maximum-scale=1` を使用していないため、アクセシビリティに必要なピンチズームを利用できます。

## 画面履歴と途中結果

ホーム、単語クイズ、文法クイズ、文法確認、各結果、単語一覧、文章一覧、声調組み合わせ表、英単語一覧の画面状態をHistory APIで管理しています。ホームから文法クイズ・文章一覧・単語一覧・声調組み合わせ表・英単語一覧へ移動した後は、ブラウザの戻るボタンやiPhone Safariの戻るスワイプを利用できます。

クイズを途中終了した場合は、答え合わせ済みの問題だけを途中結果として表示します。入力途中や未出題の問題は結果・正答率・間違い保存の対象に含みません。クイズ中にブラウザの戻る操作を行った場合も、解答履歴があれば確認済みの途中結果を表示します。

確認モードの途中終了では、「答えを見る」を押した単語だけを確認途中結果に含めます。まだ答えを表示していない現在の単語や未出題の単語は含みません。

通常結果・途中結果・確認完了・確認途中結果には、上部と下部の両方に「ホームに戻る」ボタンがあります。問題数が多い場合でも、結果一覧をスクロールする前に上部からすぐホームへ戻れます。どちらのボタンも同じHistory APIのホーム遷移処理を使用します。

文法クイズも同様に、解答済み問題がある状態で途中終了した場合は解答済み問題だけを途中結果へ表示します。未判定の入力や未出題問題は集計せず、結果画面の上部と下部のどちらからでもホームへ戻れます。

文法確認を途中終了した場合は、「答えを見る」を押した文章だけを文法確認途中結果へ表示します。まだ答えを開いていない現在の文章と未出題文章は含めません。

## ローカルでの確認方法

簡単に確認する場合は、`index.html` をブラウザで開きます。

ローカルHTTPサーバーを使う場合は、リポジトリのルートで次を実行します。

```bash
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000/` を開きます。環境によって `python` が見つからない場合は、`python3 -m http.server 8000` を使用してください。

## GitHub Pagesでの公開方法

1. GitHub上のリポジトリ名が `tyuugokugo` であることを確認します。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment** の **Source** で **GitHub Actions** を選択します。
4. `main` ブランチへpushすると、`.github/workflows/deploy.yml` がサイトを公開します。

公開URLは次の形式です。

```text
https://ユーザー名.github.io/tyuugokugo/
```

CSSとJavaScriptは相対パスで読み込むため、`/tyuugokugo/` のサブディレクトリでも動作します。

- `index.html`: 画面構造

- `grammar-data.js`: 第1課〜第6課の文法問題73項目
- `english-vocabulary.js`: Chapter共通一覧画面、意味の表示切り替え、英語画面の操作
- `english-vocabulary-data.js`: Chapter1〜Chapter7、英単語49語・英熟語21個と日本語訳
- `ranked-map.js`: JST基準のランクマップ計算、表示、1分ごとの自動更新
- `assets/images/`: Storm Point、World’s Edge、E-Districtの画像
- `speech.js`: 中国語音声の選択と再生制御
- `words.js`: lesson情報を含む77項目の単語データ
- `.github/workflows/deploy.yml`: GitHub Pagesへの公開ワークフロー
